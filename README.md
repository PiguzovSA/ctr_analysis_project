# Анализ CTR рекламных объявлений 📊

## Автор - Пигузов Стас

## Цель проекта 🎯
Анализ эффективности рекламных объявлений на основе показателя CTR (Click-Through Rate) и выявление наиболее успешных рекламных кампаний.

## Входные данные 📁
Файл: `ads_data.csv`
Содержит информацию о рекламных событиях за период с 1 по 6 апреля 2019 года.

**Структура данных:**
- `date` - дата события
- `time` - время события
- `event` - тип события (view/click)
- `platform` - платформа показа (android/ios/web)
- `ad_id` - идентификатор объявления
- `client_union_id` - идентификатор клиента
- `campaign_union_id` - идентификатор рекламной кампании
- `ad_cost_type` - тип оплаты (CPM/CPC)
- `ad_cost` - стоимость рекламы
- `has_video` - наличие видео
- `target_audience_count` - размер целевой аудитории

**Объем данных:** 1,000,000 строк

## Ход работы 🔄

### 1. Подготовка данных ⚙️
- Импорт необходимых библиотек (pandas, numpy, matplotlib, seaborn, scipy)
- Настройка визуализации и отключение предупреждений
- Загрузка и первичный анализ данных
- Проверка на пропущенные значения

### 2. Расчет CTR 📈
Созданы отдельные таблицы для:
- Количества кликов по объявлениям
- Количества показов объявлений
- Объединенная таблица с расчетом CTR = клики/показы

### 3. Разведочный анализ 🔍
- Удаление аномальных данных (CTR > 1)
- Фильтрация объявлений с количеством показов выше 20-го процентиля
- Выявление топ-10 объявлений по среднему CTR
- Детальный анализ наиболее успешных кампаний

### 4. Визуализация 📊
- Построение круговой диаграммы распределения кликов и показов
- Анализ динамики кликов и показов по датам
- Отдельная визуализация для лидирующего объявления

## Результаты 📋

### Ключевые находки:
1. **Топ-объявление**: ad_id = 112583
   - Средний CTR: 30.07%
   - Среднее количество кликов: 17,627
   - Среднее количество показов: 58,633
   - Кампания: 112260

2. **Статистика платформ**:
   - Android, iOS и Web показывают различную эффективность
   - Наибольшая активность наблюдалась 5-6 апреля 2019 года

3. **Общая эффективность**:
   - Средний CTR по всем объявлениям: значительно ниже топовых показателей
   - Среднее количество кликов на объявление: 43.77
   - Среднее количество показов на объявление: 367.99

### Выводы 💡
Объявление 112583 демонстрирует исключительную эффективность с CTR 30%, что значительно превышает средние показатели. Кампания 112260 успешно использовала единственное объявление, которое генерировало высокий трафик и вовлеченность.
